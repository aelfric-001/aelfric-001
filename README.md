Currently building **Alfi**, a lightweight C++ backend framework for practical web APIs. Alfi is developed incrementally, starting with HTTP fundamentals and moving toward PostgreSQL-backed applications. It is an exploration of clean backend architecture, networking, API design, and developer experience.

I am not trying to build a massive framework. I am trying to build one that makes sense.

## Focus
- C++
- HTTP and REST API design
- Backend architecture
- PostgreSQL and SQL
- Developer experience

## Principles
- Clarity over cleverness.
- Explicit over implicit.
- Small abstractions over large ones.
- Documentation and tests are part of the implementation.
- Build for the next developer.
